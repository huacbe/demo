# 餐厅 AI 助手 —— 使用说明

这是一个「微信小程序」的网页原型 + 向量知识库 + DeepSeek AI 对话 的完整演示项目。

## 一、项目结构

```
restaurant-ai/
├── web/                          # 网页原型（模拟小程序界面）
│   ├── index.html                # 对话窗口页面
│   ├── style.css                 # 样式
│   └── app.js                    # 前端逻辑（调后端接口）
├── backend/                      # Python 后端
│   ├── config.py                 # ★ 所有配置（模型路径、API Key、门店信息等）
│   ├── embedding.py              # 千问0.6B 封装成 Chroma 的向量化函数
│   ├── vector_db.py              # 向量库：建库/入库/检索
│   ├── ingest.py                 # 一键把知识文档灌入向量库
│   ├── app.py                    # FastAPI 后端服务（RAG + DeepSeek）
│   └── requirements.txt          # 依赖清单
├── knowledge/                    # ★ 知识库（你补充数据的地方）
│   ├── 菜品/                     # 放菜品介绍文档
│   ├── 分店/                     # 放门店信息文档
│   └── FAQ/                      # 放常见问题/餐厅文化文档
├── chroma_data/                  # 向量库落盘目录（自动生成）
└── docs/                         # 文档
```

## 二、首次运行步骤

### 第 1 步：安装依赖

在 `backend` 目录下，用虚拟环境安装（推荐）：

```bash
cd E:\demo\restaurant-ai\backend

# 创建虚拟环境（可选但推荐）
python -m venv .venv

# 激活虚拟环境（Windows）
.venv\Scripts\activate

# 安装依赖（用清华镜像加速）
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

> 注意：`torch` 体积较大（约 2GB），安装较慢。如果你的系统里已经有 torch，可以跳过。

### 第 2 步：灌入知识库

```bash
python ingest.py
```

会扫描 `knowledge/` 目录下所有 `.txt` / `.md` 文件，切块后写入向量库。

### 第 3 步：启动后端

```bash
python app.py
```

看到 `餐厅 AI 助手后端启动中……` 且模型加载完成后，后端就在 `http://127.0.0.1:8000` 运行了。

### 第 4 步：打开网页原型

- 方式 A：浏览器直接打开 `web/index.html`（后端启动后即可对话）
- 方式 B：访问 `http://127.0.0.1:8000/`（后端静态托管了网页）

## 三、日常补充知识库

随时往 `knowledge/` 对应分类文件夹里放新的 `.md` 或 `.txt` 文件，然后重新运行：

```bash
python ingest.py
```

- **同名文件** → 覆盖更新
- **新文件** → 追加
- 按子文件夹自动打分类标签（`菜品` / `分店` / `FAQ`）

## 四、修改配置

所有配置集中在 `backend/config.py`：

| 配置项 | 说明 |
|---|---|
| `QWEN_EMBEDDING_MODEL_DIR` | 千问模型路径（默认已指向你的模型） |
| `DEEPSEEK_API_KEY` | DeepSeek API Key（已填入） |
| `DEEPSEEK_MODEL` | 模型名（`deepseek-v4-flash`） |
| `BRANCHES` | 各分店信息（用于「就近门店」推荐） |
| `TOP_K` | 每次检索召回的知识片段数 |
| `SIMILARITY_THRESHOLD` | 相似度阈值（低于则丢弃） |

## 五、记忆功能（下一步扩展）

当前版本实现了「对话历史」在会话内传递。按你的需求（A 方案），后续要加：

- 用户点餐习惯记忆（存在后端，7 天重置）
- 连续 7 天无点餐 → 清除记忆
- 特殊标记用户 → 30 天压缩一次

这些需要后端接入用户身份 + 订单数据 + 定时任务，会在原型验证通过后作为第二阶段实现。

## 六、常见问题

**Q：运行报错 `ModuleNotFoundError: No module named 'xxx'`**
→ 说明依赖没装全，重新执行 `pip install -r requirements.txt`。

**Q：网页显示「无法连接后端服务」**
→ 确认已运行 `python app.py`，且后端端口是 8000。

**Q：模型加载很慢**
→ 首次加载千问模型需要几十秒到几分钟，属正常现象，请耐心等待。
